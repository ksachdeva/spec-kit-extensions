# Elephant-Goldfish Model

https://egm.dev/

This is a port of EGM for spec-kit.

## Brief Introduction

**What is EGM?**

The Elephant-Goldfish Model is a way to develop an idea with AI and review the written plan independently. The drafting assistant has the background. Fresh reviewers read the document without the conversation that produced it.

You decide which questions matter, check the facts, and approve the changes. A review is a source of feedback, not proof that a plan is correct.

## Commands


| Command | Invocation | Purpose |
|---|---|---|

| `speckit.egm.review` | `/speckit.egm.review` | Run the EGM Goldfish review protocol and remediate approved findings |
